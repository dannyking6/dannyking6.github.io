# Blog de Danny — carnet de chantier

Blog statique hébergé sur GitHub Pages (~dannyking6/dannyking6.github.io).

## Structure

- `index.html` — accueil : masthead, article à la une, sommaire numéroté
- `articles/` — un fichier HTML par article complet
- `assets/style.css` — système éditorial partagé (papier/encre, surligneur)

## Identité visuelle

- Fond papier `#F1EFE8`, encre navy `#1B2540` / `#10182B`, surligneur jaune `#F7C948`
- Titres : Bricolage Grotesque ; corps : Source Serif 4 (Google Fonts)
- Geste signature : surligneur jaune sur les phrases clés

## Coquilles corrigées par relecture

Les articles ont été relus ; si une coquille en traverse malgré tout, elle se corrige directement dans le fichier HTML correspondant.
